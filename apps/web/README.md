# Annapoorna Web Portal

Next.js 15 App Router frontend application with TypeScript, React 19, and Tailwind CSS.

## Getting Started

```bash
# Install dependencies
npm install

# Start development server
npm run dev
```

The application will be accessible at [http://localhost:3000](http://localhost:3000).

## Key Surfaces
- `/` - Public Homepage with Six Lifestyle Pillars intro
- `/pillars` - Comprehensive Six Pillars capability groups (Education, Management, Analysis)
- `/recipes` - Culinary Medicine recipe catalogue
- `/lead-guide` - Lead generation & Free Starter Guide download
- `/login` - Role-aware authentication
- `/dashboard` - Member Portal Dashboard (Current Program, Upcoming Live Classes, Meal Plan)
